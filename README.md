# Django Todo App

## Description
A basic Todo List web application developed using Django and SQLite.

## Features
- Display Todo tasks
- Show task completion status
- Mark tasks as completed

## Technologies Used
- Python
- Django
- SQLite
- HTML

## How to Run

1. Install Django
2. Run migrations:
   
   python manage.py migrate

3. Start the server:
   
   python manage.py runserver

4. Open http://127.0.0.1:8000/ in your browser.
